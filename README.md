### 📌 Featured Projects

#### 🧾 [Proofly](https://github.com/ashwathjelloji2468-gif/proofly-monorepo) — Enterprise Social Proof & Testimonial SaaS Platform
`Next.js 15` · `TypeScript` · `GraphQL` · `PostgreSQL` · `Prisma` · `Vercel` · `Render`

- Architected a full-stack SaaS platform for video & text testimonial collection with branded collection spaces, AI-powered sentiment analysis, key-phrase extraction, and automated quote generation — deployed on Vercel (frontend) and Render (backend) with Cloudinary media infrastructure.
- Built a flexible social proof widget system — marquees, floating notifications, carousels, and Walls of Love — with real-time engagement analytics and attribution tracking.
- Implemented passwordless OTP authentication with Google & GitHub OAuth 2.0, HttpOnly cookie sessions, role-based access control (RBAC), and Next.js Middleware.
- Designed the PostgreSQL schema with Prisma ORM, integrated Stripe billing, a Cloudinary video pipeline, and a GraphQL (Apollo) API layer spanning auth, billing, media, and analytics.

#### 📈 [Zerodha Kite](https://github.com/ashwathjelloji2468-gif/kite-backend) — Fintech Platform with Enterprise 2FA Security
`React.js` · `Node.js` · `MongoDB` · `Vercel` · `TOTP`

- Built a distributed fintech platform with multi-app architecture, decoupling marketing pages and the auth dashboard into isolated Vercel codebases to simulate real-world financial service routing.
- Implemented enterprise-grade cryptographic 2FA using Time-based One-Time Passwords (TOTP), syncing to authenticator apps for dynamic 6-digit login pins.
- Architected distributed service routing with AWS Lambda-compatible serverless functions handling auth state and session management across isolated deployment zones.
- Resolved complex cross-environment configuration mismatches under deployment pressure, strengthening serverless routing and CI/CD workflows on Vercel.

#### ✈️ [WanderLust](https://github.com/ashwathjelloji2468-gif/wanderlust) — Full-Stack Travel Listing Platform
`Node.js` · `Express.js` · `MongoDB` · `Cloudinary` · `AWS S3`

- Engineered an Airbnb-inspired platform with complete CRUD operations, server-side rendering via EJS, and MVC architecture.
- Implemented secure authentication and role-based authorization with Passport.js, restricting listing edits to verified owners.
- Integrated a Cloudinary media pipeline for image upload, storage, and delivery, architected for migration to AWS S3.
- Structured the codebase with MVC and Mongoose ODM for clean, maintainable, scalable backend logic.
